# CORE-X — שומר "הלוח לא מקוון"

הלוח שולח לבד התראות על מה שקורה לו (עלה אחרי תקלה, חזר חשמל, אין Art-Net וכו').
אבל כשהלוח עצמו כבוי — הוא לא יכול לשלוח כלום. את זה עושה השומר: GitHub Actions בודק כל 5 דקות
את סימן ה-online של כל לוח בשרת ה-MQTT, ושולח התראה ל-ntfy כשלוח נעלם וכשהוא חוזר.

## הגדרה (פעם אחת)
1. ב-GitHub, בריפו: Settings › Secrets and variables › Actions › New repository secret.
2. שם: `CORE_X_BOARDS`. ערך — רשימה של הלוחות, למשל:

```json
[
  {"name":"נאמי לובי","dev":"nami","host":"xxxxxxxx.ala.eu-central-1.emqxsl.com","port":8084,
   "user":"nami","pass":"הסיסמה של הטלפונים","topic":"core-x-הנושא-מההגדרות-של-הלוח"}
]
```

- `dev`, `host`, `port`, `user`, `pass` — אותם פרטים שבקישור ההזמנה (d, h, p, u, k).
- `topic` — הנושא מ"התראות לטלפון" בממשק הלוח (אותו נושא שהטלפון רשום אליו).
- אפשר להוסיף `"srv"` לשרת ntfy פרטי, ו-`"click"` לקישור שייפתח בלחיצה על ההתראה.

3. Actions › CORE-X board watch › Run workflow — הרצה ראשונה ידנית לבדיקה.

## טוב לדעת
- GitHub מריץ "כל 5 דקות" בערך — לפעמים באיחור של כמה דקות. זה לא שעון עצר, אבל מספיק לדעת שהלוח נפל.
- בריפו בלי שום שינוי 60 יום GitHub משבית ריצות מתוזמנות. אם זה קורה — Actions › Enable workflow.
- דרוש לוח v2.67 ומעלה (שם נוסף סימן ה-online).
