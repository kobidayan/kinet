# CORE-X — עדכון קושחה בלחיצה

הלוח (v2.69 ומעלה) בודק כאן אם יש גרסה חדשה, מוריד את הקובץ החתום, בודק את החתימה במפתח שלך, כותב ומאתחל.

## איך מפרסמים גרסה חדשה
1. מקמפלים ב-Arduino IDE: Sketch › Export Compiled Binary — נוצר `kinet_bridge.ino.bin`.
2. חותמים ב-kinet_signer.html (אותו מפתח של העדכון מרחוק) — יוצא קובץ `.signed`.
3. משנים לו שם לפי הלוח: `kinet_bridge_v2.70_nano.signed` (ל-ESP32-P4-NANO) או `..._eth.signed` (ל-ESP32-P4-ETH),
   ומעלים לתיקייה הזו (`fw`).
4. מעדכנים את `fw.json`: מספר הגרסה (`v`), מה חדש (`notes`), ושמות הקבצים (`files`). שומרים — וזהו.

השלט (אבחון › עדכון קושחה) והממשק (הגדרות › מערכת ועדכון › עדכון בלחיצה) יציעו "עדכן" לכל לוח בגרסה ישנה יותר.
קובץ שלא נחתם במפתח של הלוח נדחה — גם אם מישהו יחליף את הקבצים כאן.
