# CORE-X — עדכוני קושחה

הלוחות (v2.69 ומעלה) קוראים כאן את `fw.json`. כשיש גרסה חדשה לסוג הלוח שלהם — הם מציעים "עדכן"
(בשלט: אבחון; בממשק: מערכת ועדכון), ולוח עם "עדכון אוטומטי" (v2.70 ומעלה) מתעדכן לבד בשעה השקטה שלו.
כל קובץ נבדק בחתימה במפתח שלך — קובץ שלא נחתם בו נדחה, גם אם מישהו יחליף את הקבצים כאן.

## איך מפרסמים גרסה
לא עורכים כאן ידנית. בונים בריפו הפרטי של הקושחה (Actions), ומפרסמים עם `core-x-publisher.html` מהמחשב:
הוא חותם, מעלה את קבצי ה-`.signed` לתיקייה הזו, מעדכן את `fw.json` ומוחק את קבצי הגרסה הקודמת.

`"auto": false` ב-`fw.json` = הגרסה מוצעת לעדכון, אבל לוחות לא יתקינו אותה לבד.
